Help center

How to use FocusMe.

From your first launch to swapping Pip for your own artwork.

Getting started

From download to a pet on your Dock in about 30 seconds.

  1. Download FocusMe.zip and unzip it into Applications.
  2. Right-click the app → Open → Open. It's unsigned, so a normal double-click is blocked the first time; right-clicking confirms it once. If macOS says it's "damaged", run xattr -dr com.apple.quarantine /Applications/FocusMe.app in Terminal.
  3. Pip appears near your Dock and an icon lands in the menu bar — your home base for Settings, show/hide, and quit.

Meet Pip

  • Triple-tap Pip to open the chat.
  • One tap is a quick hello, drag to move it, right-click for a menu.
  • By default Pip is in peek mode — it stays tucked away and only slides up when it has a nudge for you.

Talking to Pip

Triple-tap to open the chat, then type. Commands start with /, questions end with ?.

Commands

/timer 25Start a focus session (minutes)
/stopEnd the focus session
/remind call Kavi at 5pmRemind me once
/daily 11:30 chia seedsRemind me at the same time every day
/every 2h stand and stretchRepeat on an interval
/water 30Water nudge every N min (/water off to stop)
/note buy milkSave a note
/sleep · /hide · /quitNap · hide the pet · quit
/settings · /helpOpen Settings · list everything

Questions

End any of these with ? and Pip answers instantly, all from your own Mac:

battery? memory? cpu? disk? weather? weather in Tokyo? internet? uptime? time? timer? reminders? notes?

Anything that isn't a command or a question is saved as a quick note.

Reminders & routines

Three flavours — set them by chat, or in Settings → Reminders.

One-off reminder

In chat: /remind submit report at 4pm or /remind stretch in 20 min. Or add one in Settings with a date & time.

Daily reminder

Same time every day: /daily 9am vitamins or /daily 11:30 chia seeds.

Routine (every N)

Repeat on an interval: /every 2h stand and stretch. You can give a routine an active window (e.g. only 9–6) in Settings.

Water & bedtime

Turn on sip reminders with /water 45 (or Settings → Wellbeing), and set a bedtime wind-down window there too. Both pause automatically during a focus session.

Focus sessions

A Pomodoro-style timer that keeps running even while Pip is hidden.

  • Start one with /timer 25, the menu-bar Start focus session, or Settings.
  • A countdown ring shows the time left — click it to pause, resume, or end.
  • When it finishes, Pip gives a gentle chime and suggests a break.
  • Set your default length and the chime in Settings → Focus.

Change the character

Pip is just the default — drop in any SVG or image and it becomes your pet.

  1. Open Settings → Character and choose a file (an SVG, or a PNG/JPG that gets traced into one).
  2. That's it — the whole drawing breathes, walks, and reacts. Hit Reset any time to bring Pip back.

Make parts move

Give groups in your SVG these ids (or data-part="…") and FocusMe animates them for you:

eyes / eye-left / eye-rightblink and squint
pupils (class="pupil")follow the mouse
mouthmoves while talking
arm-left / arm-rightswing while walking, wave hello
antenna / tail / earslazy sway
face / headtilt

No named parts? No problem — it just moves as one happy blob.

Customize & peek mode

Settings → Pet has all the knobs.

  • Name — what Pip calls you.
  • Size & speed — scale it up or down, set how briskly it moves.
  • Wander — little strolls along the Dock when idle.
  • Sleepy — dozes off when left alone.
  • Eyes follow cursor — Pip watches your pointer.
  • Peek mode — stays hidden off-screen and only pops up for a nudge. Turn it off to keep Pip on screen all the time.

Open at login and multi-monitor support (a pet on every screen) are on by default — find them in Settings → General.

Troubleshooting

"FocusMe is damaged / can't be opened"

It's just unsigned. Right-click the app → Open. If that still refuses, run once in Terminal: xattr -dr com.apple.quarantine /Applications/FocusMe.app

I can't see the pet

It's probably in peek mode (hidden until a nudge). Click the menu-bar icon → Show / hide pet, or turn off peek in Settings → Pet.

Reminders didn't fire after a restart

Interval routines count from when the app starts, so they reset on a restart — expected for an always-on app. One-off and daily reminders are unaffected.

Updating

Pip shows an "Update" bubble when a new version is out — download the new FocusMe.zip and replace the app.

Common questions

Is it safe to install?+
Yes. FocusMe is open source — you can read every line on GitHub. There's no account and nothing you do leaves your Mac. It just isn't code-signed with a paid Apple certificate yet, so macOS asks you to confirm the first launch (right-click → Open). After that it opens normally.
Which Macs does it run on?+
Apple Silicon Macs (M1 and newer) on macOS 11 or later.
Is it really free?+
Completely. Free and open source, no trial, no upsell, no ads.
Does it phone home or use AI?+
No cloud and no LLM — the chat answers run entirely on your machine. The only network call is a once-a-day check to GitHub for updates (and weather, if you ask for it).
How do I remove it?+
Quit it from the menu-bar icon, then drag FocusMe.app to the Trash. Nothing lingers.
